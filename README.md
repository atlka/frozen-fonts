# Frozen-Fonts
## Some fonts with font features frozen for terminal and system use
### Here are fonts freezed with [FontFreeze page](https://mutsuntsai.github.io/fontfreeze/)
* Adwaita\*SZ\*.ttf - Adwaita fonts with digit `1` without stand and slashed zero set for terminal and UI use
* FiraCodeVT-VF.ttf - Fira Code variable fonts with disabled alternatives for terminal and other apps use.
